# Sebastian Caballero Horta — Portfolio

Personal portfolio for Sebastian Caballero Horta, a Computer Systems
Engineering student and aspiring Full Stack Developer with a focus on Python
backend development and motorsport software.

## Featured project

[RaceOps](https://github.com/oraclesupreme63-droid/RACEOPS) is a
research-driven platform for small karting and grassroots motorsport teams. It
connects session context, driver feedback, technical decisions, actions and
outcomes without replacing existing telemetry tools.

## Stack

The portfolio is intentionally simple:

- Semantic HTML
- Responsive CSS
- GitHub Pages

## Local preview

Open `index.html` in a browser. No build step or dependency installation is
required.

## Deployment

Every push to `main` deploys the site through the static GitHub Pages workflow.
